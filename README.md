## 🌟 專案概述 (Overview)

本專案為 **AI-TRIZ 成語四維空間定位（量 / 價 / 亂 / 時）** 的純前端等距互動展示沙盤。  
零後端運行時（0 Node / 0 Python requirement），100% 靜態 HTML5 / CSS3 / ES6 / SVG 動態即時運算。

### 核心功能 (Key Highlights)
1. **11×11 等距等比立體沙盤投影 (Isometric Projection)**：以中軸成語為核心，向外動態射向「時（急/緩）、亂（亂/清）、價（重/輕）、量（多/少）」四大認知基底。
2. **16 組正交與自交成語心智模型**：
   - 跨維度正交組合 $C(4,2)$（如：急病亂投醫【時+亂】、眾口鑠金【量+價】）
   - 同維度自交對比（如：千篇一律【量+量】、緩不濟急【時+時】）
   - 單維度直觀指標（如：燃眉之急【時】、價值連城【價】）
3. **未觸發維度自動灰階化**：已觸發維度自帶專屬色彩光暈與流光脈衝；未觸發屬性自動進入沉靜灰階，視覺焦點精準鎖定。
4. **內建猜題對抗模式 (Quiz Mode)**：點擊地磚動態解鎖維度字根，支援鍵盤空白鍵 (Space) 一鍵隨機抽取成語。
