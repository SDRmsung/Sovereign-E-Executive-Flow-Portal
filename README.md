## 🚀 GitHub Pages 一鍵部署指南 (Quick Deployment)

本專案已完全預先修復相對路徑與 `.nojekyll` 設定，支援直接開箱部署：

1. **建立 GitHub 儲存庫**：
   - 建立一個名為 `n8n-executive-portal` 或 `Sovereign-E-Executive-Flow-Portal` 的 Repo。
2. **推送本資料夾內容至根目錄**：
   ```bash
   git init
   git add .
   git commit -m "feat: initial release of executive flow portal suite"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<你的儲存庫名稱>.git
   git push -u origin main
   ```
3. **啟用 GitHub Pages**：
   - 前往 Repo 的 **Settings** ➔ **Pages**。
   - **Source** 選擇 `Deploy from a branch`。
   - **Branch** 選擇 `main`，資料夾選擇 `/ (root)`，點擊 **Save**。
4. **即時訪問**：
   - 約 1 分鐘後即可在 `https://<你的帳號>.github.io/<你的儲存庫名稱>/` 獲得完整動態展示。
