⚡ System 1 門禁 · Jev／Laya／Kev

0-Token Classifier & Router數字＝設計預算，未實測

定位：雙塔的「推論入口」

雙塔看板描述知識的結構（大樹＝晶格階層、大樓＝NCM 平行預鑄）。Jev／Laya／Kev 描述推論時如何以最低延遲走進這個結構：不生成任何文字，只輸出「拒絕／類別＋風險／該喚醒哪一層」。

門禁元件對應雙塔錨點
Kev 確定性預檢大樓 B4 天台 · 00_L1_FailureMode 已燒結死鎖特徵（黑名單來源）
Jev 評估器大樹 Tier 1 主權根柱（21 領域閘門）· OOD＝落在晶格本體論之外
Laya 路由器大樹 L1／L2／L3 階層 ↔ 大樓 B1 階層殘差碼本（K=256/512/1024）

執行拓撲（30ms 門禁）

Request→ 並行分叉
CPU ┤Kev 預檢→ 命中黑名單／語法崩潰 →取消信號 · 直接拒絕
GPU ┤Shared Backbone（Shared Latent Rep）→ Multi-Head →Jev：意圖分類／風險評級Laya：L1／L2／L3 遮罩
↓ 通過S2 形式約束提取（Z3／CP-SAT）→中樞 Adapter 條件注入→NCM 平行預鑄

延遲預算（目標值）

Kev <2ms（CPU 並行）與 GPU 路徑重疊，不佔序列時間
Backbone <15msJev+Laya 頭餘裕

GPU 序列：特徵提取＋Jev＋Laya 目標 <20ms；門禁總上限 30ms。全部為設計預算，需以 SG0 或實機 benchmark 驗證後才可改標「實測」。

三元件算子級約束

Jev 淺層分類頭
Jev = 共享池化投影 + 淺層 MLP 頭 + 0-Token Logits 定界 + OOD 拒止
  • 禁止獨立深層 Transformer；只吃共享 pooled embedding，1～2 層線性投影。
  • 禁止呼叫 lm_head；只輸出類別 logits 與能量分數。
  • 能量分數超出晶格分佈 → 輸出拒止信號。
Laya 稀疏門控路由
Laya = TopK 稀疏門控 + L1~L3 階層遮罩 + 子圖指針分派 + 無狀態路由
  • MoE 式 router：一次內積算 Top-K，產生二元遮罩。
  • 遮罩決定喚醒哪一層碼本與 Adapter 殘差比例。
  • 不保存跨回合狀態，避免鎖競爭與延遲抖動。
Kev CPU 確定性預檢
Kev = CPU 非同步預檢 + Aho-Corasick/Regex + Bloom→精確雜湊兩段確認 + 毫秒級熔斷
  • 字串／規則匹配放 CPU，O(N) 線性掃描。
  • Bloom 只當第一道篩：命中後查精確雜湊表確認，才熔斷。
  • 熔斷＝向推論 pipeline 發出取消信號（cancel token），不必等 GPU 算完。

用詞修正（相對原稿）

原稿修正理由
零幻覺特徵初篩零生成（無生成式幻覺）不生成文字可排除生成式幻覺，但分類器仍會誤判；誤判率需實測。
微秒熔斷毫秒級熔斷（預檢 <2ms）與 <2ms 預檢預算量級一致。
硬體中斷取消 Pipeline取消信號（cancel token）一般推論框架以任務取消實作，非硬體中斷。
30ms／15ms／2ms標示為「目標」尚未有 benchmark 實測。

風險與對策

① 共享編碼器的隱性延遲

Jev、Laya 再輕，若 backbone 用 >100M 參數的雙向 Transformer（大型 BERT／BGE），光特徵提取就 15～25ms。對策：限用 MiniLM-L6、Model2Vec 靜態向量或 INT8 量化（ONNX／TensorRT）編碼器。

② Bloom 假陽性誤殺

Bloom 保證零假陰性，但假陽性率 P_fp ≈ (1 − e^(−kn/m))^k 會隨 00_L1_FailureMode 規則數 n 上升。對策：兩段確認（Bloom → Exact Hash Set），並隨 n 成長重算 m、k。

③ OOD 門檻漂移

晶格新增領域或葉片後，能量分數分佈會位移；OOD 門檻需與晶格版本一起版控並重新校準。
